# TVBox Skybox Bridge v0.3.0：长播修复

由 AI（OpenAI Codex）完成新增适配开发。

安装包已在开发对话中提供。当前网络的大文件上传写入超时，GitHub 镜像暂未上传；仓库提供完整修复源码、补丁、测试和校验记录。

针对 v2 在播放约 30 分钟后报错停止加载的反馈，修补已确认的“无流量 15 分钟清理”缺陷。SKYBOX 播放预缓存的视频时可能长时间不请求数据，这不代表播放已经结束。

- 已开始的会话不会再因流量空闲被关闭；播放结束后从转发通知点“停止”。
- 增加后台 CPU/Wi-Fi 保护，服务结束时释放。
- 短暂网络故障可重试；中途断流在文件标识及 Range 校验通过时可续传，不拼接重复或变更的数据。
- 增加 Cookie 轮换与更完整的诊断。

可直接覆盖此前的“TVBox SKYBOX”，包名和签名一致，versionCode 升为 3。

26 项真实本地 HTTP 测试、10 组外播接口测试和服务生命周期测试通过；包含模拟空闲 31 分钟后继续请求视频。这不等于 Quest 实机长播测试。未收到用户当次断流诊断，尚不能证明唯一原因；源站链接本身过期仍需重新解析。
